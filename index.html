How I ship

Most of my features follow the same spec-driven loop, with AI agents doing the drafting and me owning the decisions.

  1. Scope with the people askingSit with stakeholders until the requirement is specific enough to test.
  2. Have agents draft the planClaude and Codex produce the implementation plan, dependency map and technical spec.
  3. Review and reviseI read every plan critically and cut or reshape scope through structured feedback.
  4. Build and shipImplementation, code review, CI/CD through GitHub Actions, and release to production.

## Hi, I'm Neeraj

Full stack engineer from Hyderabad, India. I build web applications end to end, from the UI down to the APIs, databases and cloud infrastructure behind it. Lately most of my time goes into LLM-powered features: RAG pipelines, AI agents and generative content.

I enjoy taking a loosely defined problem and turning it into a clean, well-tested system.
